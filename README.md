One word an agent says when it has no idea what to do: **recalculating** — the sound a machine makes when it is lost mid-route, honest and in its own voice, no caption needed. It beats the obvious "uh-oh": a GPS says it when the road is gone, and an agent says it when the plan is.

## Run it

```sh
node main.ts
```

It writes the word to `/output/entry.txt`.
